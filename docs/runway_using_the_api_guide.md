#### Uploading base64 encoded images as data URIs
Section titled “Uploading base64 encoded images as data URIs”You can also upload base64 encoded images (as a data URI) instead of pointing to an external URL. This can be useful if you’re working with a local image file
and want to avoid an extra network round trip to upload the image.

of a URL. For more information about file types and size limits, see the Inputs page.

#### Uploading base64 encoded images as data URIs
Section titled “Uploading base64 encoded images as data URIs”You can also upload base64 encoded images (as a data URI) instead of pointing to an external URL.
This can be useful if you’re working with a local image file and want to avoid an extra network
round trip to upload the image.
To do this, simply pass the base64 encoded image string as a data URI in the <code dir="auto">uri</code> of a <code dir="auto">referenceImage</code>
object instead of a URL. For more information about file types and size limits, see the Inputs
page.
In this example, we’ll use the <code dir="auto">gen4_image</code> model to generate an image of a bunny facing the camera.
We provide a reference image of a rabbit that we use at-mention syntax to reference in the <code dir="auto">promptText</code>.
We also provide an untagged reference image that the model will use to style the output image with.
